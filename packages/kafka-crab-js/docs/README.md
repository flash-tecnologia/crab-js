# Project documentation

This directory contains the English technical documentation for `kafka-crab-js`.

The [RFC index](rfc/README.md) is the source of truth for the reviewed engineering items.
Each RFC is a small, reviewable unit with a stable number, status, decision, evidence,
and acceptance criteria. Implemented RFCs describe changes already present in the current
working tree. Proposed RFCs describe follow-up work that should be reviewed before coding.

The original Portuguese analysis remains available at [ANALISE-E-MELHORIAS.md](../ANALISE-E-MELHORIAS.md).
